# 🚀 Portfolio — sadiarnel.me

Personal portfolio built with Astro, powered by an automated IaC & CI/CD pipeline.

🌐 **Live:** [https://sadiarnel.me](https://sadiarnel.me)

---

## 🛠️ Tech Stack

* **Frontend:** [Astro](https://astro.build) (Node.js 22, pnpm)
* **IaC:** Terraform (Cloudflare DNS management)
* **Hosting:** Vercel
* **CI/CD:** GitHub Actions (`prod` branch)
